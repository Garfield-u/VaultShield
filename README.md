
# VaultShield 🔐

VaultShield is a secure password manager built with Python and Tkinter.  
It allows users to safely store, manage, and retrieve passwords using encryption and a master password system.

---

## 🚀 Features
- Master password authentication
- Secure password encryption (Fernet)
- Add, view, search, and delete passwords
- Copy passwords to clipboard
- Auto-lock on inactivity
- Login attempt protection (lockout system)
- Password aging/security checks
- Modern Tkinter GUI dashboard

---

## 🛠️ Technologies Used
- Python
- Tkinter
- Cryptography (Fernet)
- JSON for local storage

---

## 📂 Project Structure
- `src/` → Main source code
- `data/` → Stored user data and settings
- `assets/` → Screenshots, icons, logos
- `executable/` → Final build (.exe)
- `docs/` → Documentation
- `requirements.txt` → Dependencies
